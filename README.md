# Snake Java
Simple JavaFX Snake game for 1 up to 4 players.

## Disclaimer
- This project was meant as a way to learn the basic of JavaFX for my own pleasure.
- No AI has been used during development.

## Usage
Install Java 25+ on your system and execute the following to produce an OS specific executable located at `target/dist/bin/snake`: 
```
mvn javafx:jlink
```
